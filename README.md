# Cold-Tub-Engineering-Project

Documents the design and construction of backyard 100 gallon cold tub

This project includes:
- Thermal Calculations
- Cooling load analysis
- CAD design
- Pump sizing
- Heat exchanger selection
- Testing
- Cost Analysis


Objectives
- Maintain Water between 45 and 55 F
- Cool 100 gallons from room temperature in under 6 hours
- Operate from househould outlet (assume 120V)
- Contintous Operation
- Modular Design


Design Process
1. Requirements
2. System Architecture
3. Cooling Calculations
4. Component Selection
5. CAD
6. Build
7. Testing
8. Validation
